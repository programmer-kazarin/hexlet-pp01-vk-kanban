# Производственная практика ПП.01, ПП.02, ПП.04

# ТЗ
## Цель проекта
Сделать систему управления задачами: доски, колонки, карточки, участники, комментарии, дедлайны. Опционально — drag&drop и realtime.

## Описание проекта
Необходимо разработать Kanban‑доску для командной работы с задачами. Система должна позволять пользователям создавать доски, управлять колонками и карточками, назначать исполнителей, оставлять комментарии и отслеживать дедлайны.

## MVP (обязательный минимум):
* Пользователи и доступ: регистрация/логин; доска имеет владельца и участников.
* Доски: создание, удаление, редактирование; список досок пользователя.
* Колонки: создание и переименование;
* Карточки: создание и редактирование title и description; перемещение между колонками; порядок в колонке; назначение исполнителя; дедлайн.
* Комментарии: комментарии к карточке.

## Расширения:
* Теги/лейблы и фильтр по ним.
* Чек‑лист внутри карточки.
* Вложения.
* История изменений: audit log.
* Realtime‑обновления через WebSocket: перемещения и комментарии.
* Поиск по карточкам.
* Шаблоны досок.

# Setup

Команды запускаются из корня проекта. Сначала база, затем бэкенд: он подключается к PostgreSQL при старте.

## База данных

```bash
make db-start
```

Остановка:

```bash
make db-stop
```

## Frontend

Установка зависимостей:

```bash
cd frontend && npm install
```

Запуск:

```bash
make front-start
```

## Backend

Сборка:

```bash
make back-build
```

Запуск:

```bash
make back-start
```
